# Развёртывание RetailVision

Dockerfile и Compose находятся в корне репозитория. Здесь размещены Nginx TLS-template, скрипты backup/restore, контейнерный smoke-test и пустые каталоги моделей/сертификатов. Секреты, модели и настоящие сертификаты исключены из Git. [Полная инструкция](../docs/deployment.md), [результаты проверок](../docs/testing.md).

Базовый Compose поднимает публичный DEMO без административной учётной записи. Для первого администратора используется дополнительный compose.admin.yaml с файловым секретом. Публичный VPS, домен и выдача/автообновление сертификатов настраиваются владельцем отдельно.
