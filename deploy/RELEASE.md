# Проверенный выпуск для ручного развёртывания

Этот комплект создан вручную запущенным GitHub Actions workflow `Prepare deployment`. Он не подключается к VPS, не содержит паролей, обученных весов или частной базы и не публикует сайт.

1. На Linux amd64 проверьте `sha256sum -c SHA256SUMS`.
2. Выполните `gunzip -c retailvision-image.tar.gz | docker load`. Тег образа — `retailvision:<SHA из COMMIT.txt>`. Сверьте `docker image inspect` с IMAGE-ID.txt.
3. Распакуйте `source.tar.gz` в новый каталог. Скопируйте собственную конфигурацию окружения по docs/deployment.md. Задайте IMAGE_TAG равным SHA из COMMIT.txt.
4. Для обновления существующего экземпляра сначала сделайте backup и сохраните прежний COMPOSE_PROJECT_NAME, том данных, параметры сети, модели и TLS. Новый каталог без прежнего имени Compose может создать другой том — это не перенос существующих данных.
5. Запустите `docker compose up -d --no-build --wait --wait-timeout 150`. Первый запуск администратора и HTTPS описаны в docs/deployment.md.
6. Проверьте вход, DEMO, свои данные и REAL с установленной моделью. Для отката восстановите согласованную резервную копию вместе с прежним образом.

Наличие этого комплекта подтверждает проверки CI, включая Linux native dependencies, HTTPS и backup/restore с тестовым графом. Оно не подтверждает работу на конкретном VPS или качество обученной SKU-модели. Артефакт хранится в Actions 14 дней; скачайте его для передачи заранее.
