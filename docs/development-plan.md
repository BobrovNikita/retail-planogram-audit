# План разработки RetailVision

## Этап 1 — реализован 2026-10-23
- .NET 10 MVC, Core, Infrastructure, Vision; два проекта тестов.
- EF Core 10 / SQLite, миграция и идемпотентное заполнение учебного каталога.
- Русский адаптивный интерфейс: дашборд, каталог и планограммы для просмотра.
- Три воспроизводимых DEMO-сценария без загрузки пользовательских фотографий.
- Базовый алгоритм сравнения, реальные результаты DEMO, без записи посетителями в БД.
- Identity, административный вход через конфигурацию без пароля по умолчанию.
- Сборка, unit/integration-тесты, HTTP smoke-test, CI, локальные коммиты, публичный GitHub при доступной авторизации.

## Этап 2 — реализован 2026-10-24
- CRUD каталога, категории, карточки/таблица, фильтры, явные классы моделей.
- Проверка и приватное хранение изображений, нейтральная публичная упаковка.
- Визуальный редактор с drag-and-drop и альтернативными кнопками, версии и защита от конфликтов.
- Дублирование, удаление, JSON import/export по SKU; серверные ограничения и транзакционное сохранение.
- Миграция существующей БД, маркер однократного seed, независимость DEMO.
- 76 автоматических тестов и браузерная проверка desktop/mobile.

## Этап 3 — реализован 2026-10-24
- Сопоставление последовательностей с повторяющимися SKU, вставками и пропусками; базовая позиционная стратегия для сравнения.
- Все шесть типов нарушений, отдельные подтверждённые отклонения и ручные проверки.
- Геометрические допуски и назначение полки по нижней опорной точке; разворачивание фейсингов документа.
- Независимые метрики позиций, LCS, наличия SKU и фейсингов, статистика полок и полная таблица сопоставления.
- Семь фиксированных DEMO-сценариев, цветные рамки и переход от нарушения к объекту/ожидаемому месту.
- 128 автоматических тестов, проверка desktop/mobile, исправление переполнения таблицы на телефоне.

## Этап 4 — инфраструктура реализована 2026-10-25
- Изучен настоящий экспорт архитектуры YOLO26n, зафиксирован статический FP32 end-to-end контракт; native ONNX Runtime CPU, проверка SHA/metadata/классов.
- Безопасная загрузка и нормализация фото, приватные черновики со снимком планограммы, рисование и числовая калибровка полок.
- Ограниченная очередь инференса, отмена, обратные координаты, рамки и результат на фотографии; явный отказ без обученной модели.
- Python train/validate/export, проверка разметки и разделения съёмок, сравнение предсказаний PyTorch/ONNX.
- 157 .NET-тестов и 8 Python-тестов, native runtime на синтетическом графе, desktop/mobile проверка калибровки.
- Обученных SKU-весов нет; обучение и измерение точности на реальных фотографиях не выполнялись.

## Этап 5 — реализован 2026-10-25
- SQLite-история, неизменные исходные снимки, постоянные приватные копии фото, автоматическое сохранение REAL и отдельное сохранение DEMO администратором.
- Фильтры, пагинация, сравнение двух проверок, аналитика по датам/режимам и собственные REAL-данные дашборда.
- Ручные SKU/рамки, добавление/удаление, пересчёт, причины, журнал до/после, восстановление оригинала и защита конкурентных изменений.
- JSON и печатный HTML/PDF через браузер, доступ владельца ко всем производным отчётам.
- 188 .NET-тестов и 8 Python-тестов; миграция с прежними данными, копирование фото, коррекция и защита приватности.

## Этап 6 — реализован 2026-10-26
- Multi-stage Dockerfile, закреплённые SDK/runtime, app без root и read-only filesystem, постоянный том данных и read-only модели.
- Compose/Nginx с TLS, ограничением Host, доверенным конкретным proxy, отдельным динамическим диапазоном IP и отсутствием публичного порта Kestrel.
- Bootstrap-secret из файла, стабильные Data Protection keys, HTTP health check для контейнера, лимиты ресурсов/логов.
- Backup с остановкой app, SHA-256 и восстановление только в пустой том; container CI проверяет HTTPS, DEMO, вход, фото, перезапуск и восстановление.
- 199 .NET + 8 Python-тестов; отдельный Docker verify-target проверяет SkiaSharp и синтетический ONNX на runtime-базе. Успешные CI-прогоны фиксируются в testing.md.

## Первый ML-эксперимент — выполнен 2026-10-26
- Подготовлен HoloSelecta: 243 пригодных фото, восемь конкретных продуктов, разделение целыми датами, хэши и журнал исключений; иллюстрации каталога только из train.
- Проверена RTX 3050/CUDA 13.0, обучена YOLO26n (20 эпох с ранней остановкой, выбран checkpoint эпохи 8).
- Выполнены независимая от обучения оценка test, ONNX export/parity на 30 фото и C#-инференс на 29 test-фото.
- Через локальный сайт добавлен ассортимент и сохранён настоящий REAL-отчёт. Модель явно обозначена экспериментальной.
- 199 .NET + 14 Python-тестов. [Измерения и ограничения](experiments/holoselecta-v1/README.md): test mAP@50 60,3%; C# recall при пороге 50% — 33,2%. Для автоматической приёмки недостаточно.

## Второй ML-эксперимент — выполнен 2026-10-26
- Исправлен выбор checkpoint: train передаёт nms=False, чтобы validation и ONNX использовали одну one-to-one ветвь; добавлен регрессионный тест, всего 15 Python-тестов.
- YOLO26s обучена на RTX 3050 и выбрана по val mAP50–95 среди трёх кандидатов. Данные и состав восьми SKU не менялись.
- На прежних 29 снимках: mAP@50 95,6%; C# precision 95,4%, recall 80,8% при пороге 50%. После анализа v1 это известный набор для проверки регрессий, а не новая независимая приёмка.
- Parity на 30 фото прошла; модель подключена локально, новый REAL-отчёт сохранён, предыдущие результаты доступны. [Измерения и ограничения](experiments/holoselecta-v2/README.md): M&M’s пока обнаруживается недостаточно надёжно, нужны новые снимки и ручная проверка.
