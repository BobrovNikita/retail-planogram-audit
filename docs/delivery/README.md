# RetailVision: комплект для демонстрации и передачи

Состояние приложения: 0.8, сверка с исходным ТЗ от 27 октября 2026 года. Комплект предназначен для демонстрации курсового проекта. Он не заменяет оформление пояснительной записки по требованиям учебного заведения.

| Материал | Для чего нужен |
|---|---|
| [Готовность по ТЗ](requirements-matrix.md) | Требования, подтверждающие файлы и оставшиеся ограничения |
| [Сценарий демонстрации](demo-script.md) | Показ на 10–12 минут и короткий вариант на 5 минут |
| [Руководство пользователя](user-guide.md) | Каталог, планограммы, фотоаудит, исправления и отчёты |
| [Вопросы для защиты](defense-qa.md) | Архитектура, алгоритмы, метрики, эксперименты и ограничения |
| [Передача и запуск](handoff.md) | Запуск на другом Windows-компьютере, состав архива, устранение ошибок |

Основной результат: каталог и редактор планограмм, общий алгоритм сравнения для DEMO и REAL, C# ONNX-инференс, приватная история с ручными исправлениями и подготовка к Linux-развёртыванию. Для REAL приложена отдельная экспериментальная модель восьми товаров HoloSelecta.

Подтверждённая исходная версия приложения — коммит `c5c8bcbcfdb15dd135d924ddc6067c031937e500`: [CI](https://github.com/BobrovNikita/retail-planogram-audit/actions/runs/40397716722), [серверный выпуск](https://github.com/BobrovNikita/retail-planogram-audit/actions/runs/40397732705). Прошли 206 .NET-тестов, 15 Python-тестов и контейнерные проверки. Точный коммит передаваемого комплекта записывается в `DELIVERY.json`; документы могут быть новее указанного серверного образа.

Для защиты достаточно локального компьютера. Первый запуск из исходников требует .NET SDK 10.0.400 и доступа к NuGet. Python и GPU нужны для повторного обучения, но не для работы готовой модели. Новая база создаётся без чужих учётных записей и отчётов.

Не следует утверждать, что модель распознаёт произвольный ассортимент, что достигнута «точность системы 95,4%» или что уже работает публичный VPS. Значение 95,4% — precision детектора на известном наборе из 29 снимков при определённых порогах; recall на нём — 80,8%. [Подробный протокол](../experiments/holoselecta-v2/README.md).
