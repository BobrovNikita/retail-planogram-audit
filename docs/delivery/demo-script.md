# Сценарий демонстрации на 10–12 минут

Цель показа: доказать работу приложения от эталона до объяснимого отчёта, разделяя алгоритм сравнения и качество детектора. Формулировки ниже — заготовка выступления, а не заявление о промышленной готовности.

## Подготовка до выступления

1. Выполнить [установку](handoff.md) в отдельную демонстрационную базу. Не использовать рабочие отчёты для тренировочных изменений.
2. Проверить вход, страницу «Настройки»: `holoselecta-snacks-v2-experimental`, восемь активных SKU. Если порт 5180 занят другим экземпляром, запустить демонстрацию на 5181 и везде использовать этот адрес.
3. Найти `sample/photo.jpg` в каталоге данных. Один раз пройти REAL-сценарий и сохранить отчёт для резервного показа. Его ID определяется установкой; не рассчитывать на фиксированный `/History/Details/4`.
4. Открыть вкладки: `/catalog`, `/planograms`, `/audit`, `/photoaudit`, `/history`, `/home/settings`. Проверить масштаб браузера 100% и читаемость на проекторе.
5. Сохранить JSON контрольного отчёта и при необходимости его PDF через «Печать / PDF». Подписать их как результаты контрольного, уже использовавшегося снимка. Не добавлять пароль или частную БД в материалы сдачи.

## Основной показ

| Время | Действия | Что объяснить и проверить |
|---|---|---|
| 0:00–0:45 | Открыть главную | «RetailVision сравнивает выкладку с планограммой и помогает проверить отклонения». Пустой дашборд новой базы допустим; цифры появляются из собственных REAL-отчётов |
| 0:45–1:30 | Каталог: найти Snickers, открыть карточку администратора | SKU — идентификатор товара, индекс класса — отдельная привязка к версии модели. Наличие карточки само по себе не обучает нейросеть |
| 1:30–2:45 | В списке планограмм дублировать учебную схему, открыть копию; переставить позицию, изменить фейсинги, сохранить и открыть повторно | Планограмма — упорядоченный эталон. Изменять только копию. Показать версию и JSON-экспорт; контрольную схему HoloSelecta оставить для REAL |
| 2:45–4:30 | «Аудит витрины»: последовательно A, B, C | A: позиции 100%, 0 отклонений. B: 87,5%, один пропуск. C: позиции 75%, LCS 87,5%, наличие SKU 100%, два отклонения. Нажать на проблему и показать подсветку |
| 4:30–5:00 | Открыть «Настройки» | «До этого были fixture-детекции; теперь используется подключённая ONNX-модель на CPU». Показать версию и покрытие восьми SKU |
| 5:00–7:15 | `/photoaudit`: выбрать «HoloSelecta · 8 продуктов · контрольный снимок», загрузить `sample/photo.jpg`; задать полосы из таблицы ниже, сохранить границы, распознать | На фото появляются реальные предсказания, затем автоматически сохраняется отчёт REAL. Отметить порог 50%, модель и случаи ручной проверки. Не обещать конкретный процент соответствия как точность модели |
| 7:15–8:30 | «Исправить детекции»: сверить один объект с фото; при реальной ошибке исправить SKU/рамку или добавить пропущенный объект, подтвердить вручную, указать причину и сохранить | Исходная confidence остаётся в снимке; исправление имеет автора, причину и отдельную редакцию. Не подгонять результат под 100%. Если ошибки уверенно не видно, показать интерфейс и отменить правку |
| 8:30–9:30 | История: фильтры, подробный отчёт, JSON, «Печать / PDF»; при двух отчётах — сравнение | История хранит снимок эталона и исходные детекции. Разные модели/пороги означают разные условия сравнения |
| 9:30–10:15 | Учебный отчёт отправить «В корзину», открыть корзину, восстановить | Это обратимое действие; метрики и фото сохраняются. Защитный срок по умолчанию 30 дней; окончательное удаление сейчас не показывать |
| 10:15–11:30 | Показать схему архитектуры, страницу успешного CI и карточку эксперимента | Четыре слоя; 206 .NET + 15 Python-тестов; Docker проверен в CI. На известных 29 фото precision 95,4%, recall 80,8%. Новая независимая приёмка и VPS ещё впереди |

Порядок действий и названия кнопок сверены с текущими контроллерами и Razor Views. Метрики A/B/C взяты из фиксированных примеров и тестов, а не придуманы для выступления. Демонстрационный эталон не меняется при редактировании каталога и планограмм.

## Полосы для приложенной фотографии

Для всех полок: слева 0%, справа 100%. Не переносить эти числа на другое фото.

| Полка | Сверху | Снизу |
|---|---:|---:|
| 1 | 18% | 31% |
| 2 | 31% | 39% |
| 3 | 39% | 47% |
| 4 | 47% | 58% |

Нажать «Сохранить границы», дождаться подтверждения, затем «Распознать товары». Полоса включает нижнюю опорную точку товара, а не обязательно всю рамку упаковки. Контрольное фото уже использовалось при оценке и не доказывает перенос на новый магазин.

## Вариант на пять минут

1. 30 секунд: задача и архитектура.
2. 45 секунд: каталог и сохранённая планограмма.
3. 60 секунд: DEMO B/C и разница позиционной/LCS-метрик.
4. 90 секунд: REAL на подготовленной калибровке либо честно обозначенный ранее сохранённый REAL-отчёт.
5. 45 секунд: журнал, JSON, печать.
6. 30 секунд: тесты, измерения и ограничения.

## Если показ прервался

| Ситуация | Действие |
|---|---|
| Модель не подключена или отклонена | Показать статус в «Настройках», продолжить DEMO. Сохранённый REAL-отчёт назвать ранее полученным результатом, а не новым распознаванием |
| Нет интернета | После успешного restore/build локальная демонстрация не требует сети. Для CI и исходников использовать заранее сохранённые материалы; не утверждать, что текущая проверка запущена онлайн |
| Сервис занят | Дождаться завершения текущего анализа и повторить один запрос. Не отправлять много запросов подряд |
| Не сохранилась калибровка | Проверить все четыре полосы и дождаться подтверждения сохранения. Проценты должны относиться к показанному фото |
| Конфликт версии после правок | Скопировать несохранённые значения для себя, открыть актуальную запись и перенести нужные изменения. Не обновлять страницу вслепую |
| Сайт не запускается | Проверить [ошибки запуска](handoff.md); использовать JSON, PDF и [сохранённые снимки интерфейса](../images). Назвать это резервными материалами, не живой демонстрацией |

Фраза завершения: «Реализована полная учебная цепочка аудита. Качество детектора ограничено восемью SKU и известной выборкой; следующий этап — независимые фотографии и проверка на целевом сервере».
