# Проверки

Локальная среда проверки: Windows, .NET SDK 10.0.400, runtime 10.0.11. Release build: 0 ошибок/предупреждений. EF не обнаруживает изменений модели после InitialCreate migration.

```sh
dotnet restore --locked-mode
dotnet build --configuration Release --no-restore
dotnet test --configuration Release --no-build --logger trx
```

14 unit-тестов: три fixtures, пропуск без каскадного сдвига, повторяющиеся SKU, лишний фейсинг, неправильная полка, низкая уверенность/неизвестный SKU, пустая витрина, пустой эталон, дубликаты позиций, отказ обрабатывать произвольное изображение fixture-детектором.

18 интеграционных тестов через WebApplicationFactory и настоящую временную SQLite: восемь публичных страниц/health, три POST DEMO и отсутствие записи истории, CSRF, недопустимый fixture, авторизация настроек, вход администратора с защитой от open redirect, миграция/идемпотентность seed, поиск каталога, rate limiting. Тестовые пароли генерируются на запуск, временные папки удаляются после остановки приложения.

HTTP smoke-test: главная страница возвращает 200, `/health` — Healthy. Браузерная проверка включает desktop 1440px, mobile 390px, отправку сценария с пропуском, результат 87,5% и кнопку подсветки ожидаемого слота. В консоли нет ошибок. Скриншоты хранятся в `docs/images/`.

CI workflow выполняет те же сборку и тесты на Ubuntu, хранит TRX. Результаты для конкретного коммита доступны в GitHub Actions; наличие workflow само по себе не означает успешную проверку. Проверка Linux-контейнера, реального ONNX и нагрузочные испытания пока не выполнялись.

Подтверждён успешный запуск CI для коммита приложения `eabb97897dd0afb36afaa5e63874de9acfc0e456`: [run 39982333189](https://github.com/BobrovNikita/retail-planogram-audit/actions/runs/39982333189). Сборка и все 32 теста прошли на Ubuntu.
