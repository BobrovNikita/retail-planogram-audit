# HoloSelecta: первая обученная модель, 2026-10-26

**Статус: экспериментальная, для автоматической приёмки выкладки не готова.** Восемь классов конкретных упаковок обучены на RTX 3050, экспортированы в ONNX и проверены через настоящий C#-инференс и локальный сайт. Веса и фотографии хранятся локально, в Git включены код, профиль, происхождение данных и измерения. Метка REAL означает вызов обученной модели, а не подтверждённую достоверность её ответа.

## Источник и подготовка

[HoloSelecta v1](https://data.mendeley.com/datasets/gz39ggf35n/1), DOI [10.17632/gz39ggf35n.1](https://doi.org/10.17632/gz39ggf35n.1). Авторы: Klaus Fuchs, Tobias Grundmann, Mirella Haldimann, Elgar Fleisch, 2020. Лицензия данных: [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Производные изображения уменьшены с сохранением пропорций до 1600 px, перекодированы в JPEG; иллюстрации каталога вырезаны из train. VOC-разметка преобразована в YOLO, оставлены только выбранные восемь классов. Attribution относится также к профилю, разметке, иллюстрациям и контрольному примеру.

Опубликованный ZIP размером 2 122 992 435 байт имеет SHA256 `4492e5f544a035cf4884626187ebf39ab5e703f71a3ff05733b6c11baf926afb`. В нём 295 XML, но 277 фотографий. Исключены 18 отсутствующих изображений, 31 DSC-файл без подтверждённой даты/происхождения (среди них похожие производные кадры), один файл с несовпадением размера XML и изображения, два снимка электронного меню вместо физических товаров. Исходные Python/pickle-файлы не выполнялись. Все исключения перечислены в [отчёте подготовки](preparation-report.json).

| Выборка | Фото | Целевые упаковки | Фото без целевых SKU |
|---|---:|---:|---:|
| Train | 173 | 907 | 27 |
| Val | 41 | 271 | 7 |
| Test | 29 | 229 | 0 |

Val: вся дата 2019-02-06; test: 2019-04-30 и 2019-05-02; остальные назначенные даты — train. Ни одна дата и ни один идентичный подготовленный файл не пересекают выборки. Снимки одной даты не разбиваются. Однако **одни и те же автоматы и похожие раскладки могут повторяться между датами**: это проверка переноса между съёмками, не между независимыми магазинами. Число независимых контрольных сессий — две, поэтому 229 упаковок нельзя считать 229 независимыми экспериментами. Test не использовался для выбора эпохи, порогов или повторного обучения.

Не выбранные продукты считаются фоном. Модель не обнаруживает произвольный товар и не распознаёт ассортимент магазина целиком. Профиль использует собственные SKU `HS-*`: GTIN и размеры из источника не проверены по актуальному реестру. В частности, у M&M’s разметка указывает 45 г, метаданные — 90 г; у Snickers разметка — 50 г, метаданные — 5 г. Эти противоречия не используются как достоверные характеристики товара. Полное соответствие индексов: [профиль](../../../ml/profiles/holoselecta-snacks.json).

## Обучение и измерения

Python 3.12.14; torch 2.14.1+cu130; torchvision 0.29.1+cu130; Ultralytics 8.4.187; RTX 3050 8 GiB, драйвер 610.88. [Полный состав окружения](gpu-environment.txt). Исходный checkpoint: официальный `yolo26n.pt`, release `ultralytics/assets v8.4.0`; 696/708 компонентов перенесены в модель с восемью классами. Хэши весов и экспорта: [artifact-hashes.json](artifact-hashes.json).

Параметры: imgsz=640, batch=8, workers=2, device=0, seed=42, AMP, optimizer=auto, остальные параметры Ultralytics по умолчанию. Максимум 50 эпох, patience=12. Ранняя остановка после 20 эпох; лучший checkpoint — эпоха 8, выбран по val mAP50–95. Обучение заняло около двух минут без установки окружения и подготовки данных. [Журнал эпох](training.csv). Внешняя синхронизация и облачные логгеры были выключены.

| Измерение | mAP@50 | mAP@50–95 |
|---|---:|---:|
| Val лучшей эпохи, стандартная валидация обучения | 97,7% | 67,5% |
| Test, FP32 и полный letterbox 640×640 | **60,3%** | **39,9%** |

Первый диагностический запуск test с прямоугольными батчами дал 60,3% / 40,2% ([исходный JSON](test-rect-diagnostic.json)). Затем та же неизменная модель проверена с квадратным входом, соответствующим контракту сайта ([основной JSON](test-metrics.json)). Это проверка пути инференса, а не новый подбор модели по test. Большое падение относительно val указывает на слабый перенос на другие съёмки; высокий val не считается готовностью.

| Класс | Test mAP@50, квадратный вход |
|---|---:|
| Snickers | 67,7% |
| Twix | 23,8% |
| M&M’s Peanut | 85,7% |
| Knoppers | 81,4% |
| BiFi Roll | 48,2% |
| Zweifel Paprika | 50,3% |
| Oreo | 45,7% |
| Maltesers | 80,0% |

Отдельно измерен **реальный C#-путь**: SkiaSharp → статический ONNX FP32 → обратные координаты, на всех 29 test-фото. При заранее заданных confidence=0,5 и IoU=0,5: 76 TP, 32 FP, 153 FN; micro precision **70,4%**, recall **33,2%**, F1 **45,1%**. Модель пропускает около двух третей целевых упаковок при этом пороге. Медиана DetectAsync на CPU — 81,1 мс (включает подготовку тензора, исключает первоначальное чтение/нормализацию фото). Это не замер под серверной нагрузкой. [Метрики C#](native-metrics.json). P/R в Ultralytics вычисляются при его рабочей точке, поэтому напрямую сравнивать их с фиксированным порогом сайта нельзя.

Экспорт: `[1,3,640,640] → [1,300,6]`, FP32, opset 17, end-to-end, без внешней NMS. PyTorch/ONNX parity проверена на всех 29 test-фото и одном горизонтальном train-фото: все 30 прошли; максимальное отличие координат 0,000046 px входа, confidence 0,0000043. [Отчёт](export-parity.json). Это численная проверка экспорта, не оценка точности и не обещание идентичности интерполяции OpenCV/SkiaSharp.

## Подключение и границы проверки

Локально через защищённые MVC-формы созданы восемь товаров с иллюстрациями из train и [контрольная планограмма](sample-planogram.json), составленная из исходной разметки `IMG_20190430_105750.jpg`. Фото из test загружено, четыре полки откалиброваны, REAL-анализ автоматически сохранился в историю. Прежние DEMO-товары и отчёты сохранены. Проверено 199 .NET-тестов и 14 Python-тестов; model probe дополнительно выполнил C#-инференс всех 29 фото.

Для этого контрольного снимка нормализованные области полок (left=0, right=1): 1 — top=0,18 / bottom=0,31; 2 — 0,31 / 0,39; 3 — 0,39 / 0,47; 4 — 0,47 / 0,58. Разметка эталона не построена из предсказаний модели. В эталон входят только восемь выбранных продуктов.

Повторный запуск обучения и экспорта: [инструкция](../../../ml/README.md#профиль-holoselecta). На другом экземпляре приложения сначала создайте товары с точными SKU из профиля и затем импортируйте sample-planogram.json; текущий DEMO seed остаётся отдельным. Фотографии каталога находятся в `prepared/catalog/<SKU>.png` и доступны только администратору.

Для применения вне эксперимента нужны дополнительные размеченные съёмки целевых полок/автоматов, проверка спорных SKU, отдельные машины/локации для train/val/test и новая неизменяемая контрольная выборка. Особенно слабые классы — Twix, BiFi, Oreo; необходимы разные масштабы, блики и ракурсы. После просмотра текущего test его нельзя незаметно использовать как независимый контроль следующей серии улучшений. Порог нельзя понижать только ради красивого результата на этих 29 кадрах. Веса не следует считать пригодными для автоматической приёмки без ручной проверки.
