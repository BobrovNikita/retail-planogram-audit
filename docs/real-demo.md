# Переносимая REAL-демонстрация HoloSelecta v2

Нужны .NET SDK из global.json и отдельный архив `RetailVision-HoloSelecta-v2.zip` (53 294 010 байт). Python, CUDA и видеокарта для запуска не нужны. Архив содержит экспериментальную модель восьми упаковок, разрешённые производные изображения HoloSelecta, контрольную фотографию и планограмму. Веса не входят в Git; архив нужно передать вместе с исходниками.

Проверенный SHA-256 архива:
`c7fffc4ece1b7c47027b3340d18bfdb37e7f788f87c9e4e54f46b4d0da8b0480`.

## Установка на чистую базу

Из корня репозитория:

```powershell
dotnet restore --locked-mode
dotnet build -c Release --no-restore
dotnet run --project tools/RetailVision.DemoSetup -c Release --no-build -- "C:/Demo/RetailVision-HoloSelecta-v2.zip" "C:/Demo/retailvision-data"
```

Подставьте свои абсолютные пути. Родительская папка должна существовать, конечная `retailvision-data` — нет. Установщик отказывается изменять любой существующий каталог. Он проверяет размер и SHA архива, соответствие SKU, контракт ONNX и настоящий CPU-инференс на примере. Затем создаёт отдельную SQLite-базу, 6 исходных DEMO-товаров, 8 продуктов HoloSelecta с иллюстрациями, привязки классов и две планограммы. Готовый каталог появляется только после успешной подготовки. При сбое временная папка `.retailvision-setup-*` сохраняется для диагностики; действующие данные не меняются.

Установщик не создаёт администратора и не заполняет историю вымышленными аудитами. Каталог данных приватный: не помещайте его в Git или wwwroot. При повторной установке укажите другое новое имя папки; для обычного перезапуска установщик не нужен.

## Первый запуск в Windows

```powershell
./scripts/start-real-demo.ps1 -DataDirectory "C:/Demo/retailvision-data" -AdminEmail "your-admin@example.com"
```

Скрипт запросит новый пароль скрытым вводом: минимум 12 символов, строчные и прописные буквы, цифра и специальный символ. Пароль не записывается в файл или командную историю. Адрес служит идентификатором входа; письмо не отправляется. Существующей учётной записи bootstrap пароль не меняет.

Откройте http://localhost:5180, войдите созданной учётной записью. Скрипт запускает только локальный Development HTTP; для публичного сервера используйте [инструкцию развёртывания](deployment.md). Остановите Ctrl+C. При следующих запусках опускайте `-AdminEmail`. Если порт занят, добавьте `-Port 5181`. Скрипт восстанавливает прежние переменные процесса после остановки.

## Демонстрация

1. Откройте «Настройки»: подключена `holoselecta-snacks-v2-experimental`, все восемь SKU присутствуют и активны.
2. Откройте «Аудит витрины» → анализ фотографии, выберите «HoloSelecta · 8 продуктов · контрольный снимок».
3. Загрузите `sample/photo.jpg` из созданного каталога данных.
4. Для всех полок задайте слева 0%, справа 100%; вертикальные границы:

| Полка | Сверху | Снизу |
|---|---:|---:|
| 1 | 18% | 31% |
| 2 | 31% | 39% |
| 3 | 39% | 47% |
| 4 | 47% | 58% |

5. Оставьте порог 50%, сохраните границы и запустите распознавание. Проверьте метку REAL и версию модели; отчёт автоматически сохранится в историю.
6. Покажите неуверенные детекции, ручную коррекцию и пересчёт; исходные значения останутся в журнале. Откройте экспорт JSON и печатный отчёт.
7. Отдельно покажите три DEMO-сценария: правильная выкладка, пропуск и перестановка. Они используют fixture-детекции и явно обозначены как DEMO.

Контрольный снимок уже использовался при оценке. Он демонстрирует работу приложения, а не является независимым доказательством качества. Процент соответствия планограмме не равен точности распознавания. M&M’s и Twix могут пропускаться; посторонний ассортимент может игнорироваться. [Измерения и ограничения](experiments/holoselecta-v2/README.md).

## Linux

Установщик .NET имеет те же аргументы и не требует PowerShell. Для локального запуска задайте абсолютные `Storage__DataDirectory` и `Vision__ManifestPath` (файл `model/manifest.json` внутри каталога), `ASPNETCORE_ENVIRONMENT=Development`. Первую учётную запись создайте через .NET User Secrets или защищённый файл `Admin__PasswordFile`, как описано в deployment.md. Не передавайте пароль аргументом командной строки.

При переносе в Docker отдельно подключите созданную базу/изображения как каталог данных и `model/` как read-only модели, настройте `VISION_MANIFEST_PATH=/models/manifest.json`. Упаковка Windows не является доказательством запуска обученной модели на Linux; такой запуск проверяется отдельно на выбранном хосте.
