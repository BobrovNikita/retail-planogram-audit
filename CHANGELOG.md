# Изменения

## 0.3.0 — 2026-10-24 / этап 3
- Реализовано детерминированное сопоставление по последовательности и геометрии; сохранён базовый позиционный вариант для сравнения.
- Добавлены WrongProduct, полный результат сопоставления и объяснения; все шесть типов нарушений разделяются на подтверждённые и требующие проверки.
- Добавлены геометрические допуски, назначение полок по нижней опорной точке, разворачивание фейсингов и проверка входных данных.
- Выделены метрики позиций, порядка LCS, наличия SKU и количества фейсингов, статистика по полкам.
- DEMO расширен до семи сценариев fixture-v2; перестановка соседних товаров теперь показывает две неверные геометрические позиции (75%), отдельно от LCS (87,5%).
- Обновлён отчёт: серые неопределённые объекты, красные отклонения, таблицы соответствий/количеств и описание формул. Исправлено горизонтальное переполнение на мобильной ширине.
- 74 unit-теста и 54 интеграционных теста, включая независимую проверку коротких LCS, граничные входы, one-to-one, null SKU и семь HTML-отчётов. Схема БД и зависимости не менялись.
- Коммит приложения aa1c5d4 опубликован; все 128 тестов прошли на Ubuntu 24.04 в [CI](https://github.com/BobrovNikita/retail-planogram-audit/actions/runs/40121419986). Обновлены методика расчёта, ограничения и скриншоты desktop/mobile.

## 0.2.0 — 2026-10-24 / этап 2
- Добавлено управление каталогом: создание, редактирование, фильтры, карточки/таблица, новые категории, отключение и удаление с проверкой связей.
- Реализованы явные привязки классов моделей, уникальность SKU и защита от сохранения устаревшей версии товара.
- Изображения проверяются по содержимому, ограничиваются размером/разрешением, переориентируются и перекодируются в PNG через SkiaSharp; хранятся вне webroot и доступны только администратору.
- Добавлен визуальный редактор с drag-and-drop, кнопками перемещения, выбором полки, фейсингами, сохранением и повторным открытием.
- Реализованы независимое дублирование, импорт/экспорт JSON по SKU, удаление планограмм и серверная валидация.
- Добавлена миграция CatalogEditing, проверена модернизация существующей БД. Маркер seed предотвращает повторное заполнение удалённого каталога.
- DEMO отделён от редактируемого каталога и планограмм. Все операции записи требуют административной роли и CSRF.
- Проверки расширены до 34 unit- и 42 интеграционных тестов. В браузере проверены перетаскивание, перенос между полками, немедленное сохранение фейсингов и мобильная ширина 390 px.
- Код опубликован коммитом 155eaab; все 76 тестов прошли на Ubuntu 24.04 в [CI](https://github.com/BobrovNikita/retail-planogram-audit/actions/runs/40090823741). Добавлены руководство каталога/редактора и скриншоты.

## 0.1.0 — 2026-10-23 / этап 1
- Созданы MVC solution, Core, Infrastructure, Vision и проекты тестов.
- Настроены .NET 10, EF Core 10, SQLite, Identity и GitHub Actions.
- Создан публичный репозиторий и опубликован каркас (`7a8993a`).
- Добавлена InitialCreate migration: каталог, планограммы, модели/классы, таблицы будущей истории, Identity.
- Реализованы seed из шести SKU и восьми фейсингов, три fixture-сценария, LCS-анализатор.
- Создан адаптивный русский интерфейс, каталог с поиском, визуальный просмотр планограмм, SVG-отчёт.
- Защищены административный вход и настройки; добавлены CSRF, ограничение запросов и health check.
- Добавлены 14 unit- и 18 интеграционных тестов, проверены desktop/mobile UI и HTTP.
- Подготовлена документация архитектуры, алгоритма, БД и локального запуска.
- Коммит приложения `eabb978` опубликован, GitHub Actions на Ubuntu завершился успешно; добавлены скриншоты desktop/mobile и ссылки на официальные источники.
- GitHub Actions обновлены на Node.js 24, закреплены по полным SHA официальных релизов; runner закреплён как Ubuntu 24.04.
- Реальный ONNX, CRUD/редактор, сохранение аудитов и production-развёртывание остаются следующими этапами.
